# Insight_em_Dados
Bem-vindo ao repositório oficial do canal **[Insight em Dados](https://www.youtube.com/@InsightemDados)**! 

Aqui você encontrará todos os materiais de apoio, scripts e datasets utilizados nos nossos tutoriais em vídeo. O foco deste espaço é compartilhar conhecimento prático sobre **Análise de Dados, Data Science e Business Intelligence (BI)**.

## 🗂️ Como este repositório está organizado?

Para facilitar os seus estudos e acompanhamento dos vídeos, os materiais estão divididos em pastas individuais. Cada pasta corresponde a um tutorial específico do canal e contém tudo o que você precisa para reproduzir a análise localmente:

*   **Jupyter Notebooks (`.ipynb`):** Códigos passo a passo utilizando Python.
*   **Datasets (`.csv`, `.xlsx`, etc.):** As bases de dados utilizadas nos projetos (quando permitidas pelas licenças originais).
*   **Materiais extras:** Qualquer outro arquivo mencionado durante os vídeos.

A estrutura segue a ordem cronológica de lançamento:
* `001_Nome_do_Video/`
* `002_Nome_do_Video/`
* ...
