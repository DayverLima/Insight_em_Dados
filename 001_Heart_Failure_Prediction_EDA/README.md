# 🫀 Análise Exploratória: Previsão de Doenças Cardíacas

Bem-vindo(a) ao repositório de material de apoio do canal **Insight em Dados**! 📊

Este diretório contém o projeto passo a passo de Análise Exploratória de Dados (EDA) utilizando o **Heart Failure Prediction Dataset**. O objetivo principal desta análise é investigar a base de dados, realizar a limpeza e identificar padrões visuais sobre os fatores de risco associados a doenças cardíacas.

## 📂 O que você vai encontrar aqui?
- `heart.csv`: O conjunto de dados original utilizado na análise.
- `Heart_Failure_Prediction_Dataset.ipynb`: O Jupyter Notebook contendo todo o código Python da nossa aula.
- `LICENCA.txt`: Informações sobre a licença ODbL 1.0 que rege o uso destes dados.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python
- **Bibliotecas:** Pandas (para manipulação e limpeza) e Matplotlib/Seaborn (para visualização de dados).

## 🚀 Como utilizar este material
Para replicar esta análise na sua máquina, siga os passos abaixo:
1. Faça o download dos arquivos desta pasta.
2. Certifique-se de ter o ambiente Python e o Jupyter Notebook instalados.
3. Instale as bibliotecas necessárias rodando o comando no seu terminal: 
   `pip install pandas matplotlib seaborn`
4. Abra o arquivo `.ipynb` no Jupyter e execute as células bloco a bloco acompanhando a explicação do vídeo!
